¡Bienvenido a tu proyecto de Remotion!

## Comandos

**Instalar dependencias**

```console
npm i --loglevel=error
```

**Abrir la vista previa (Remotion Studio)**

```console
npm run dev
```

**Renderizar el video**

```console
npx remotion render
```

**Actualizar Remotion**

```console
npx remotion upgrade
```
